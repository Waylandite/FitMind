# FitMind 首页与登录页设计方案（历史归档）

> 本文档记录早期视觉探索，已被当前 Web 登录页实现替代，仅保留作设计演进参考。

## 1. 设计目标

FitMind 的首页和登录页不应该是普通表单页，而应该在第一次打开时就让用户感受到：

- 这是一个高端、可信、智能的健身与健康助手
- 它不仅能记录训练，还能理解状态、饮食和恢复
- 它具备“会对话、会记忆、会分析”的产品气质

因此首版页面采用：

- `整体深色`
- `左侧内容压缩聚焦`
- `右侧浅色登录区`
- `中间丝滑曲线切割`
- `中文文案`
- `高质感、流动感、未来感`

---

## 2. 视觉方向

### 2.1 整体风格

页面风格定义为：

`夜间高性能训练舱 + 健康智能中控台`

关键词：

- 深色背景
- 冷暖撞色高光
- 大面积留白与局部发光
- 曲线切割而非硬分栏
- 玻璃质感与柔和阴影
- 高级动效而非夸张动效

### 2.2 配色方案

主色建议：

- 背景主色：深墨黑 `#07111a` 到 `#0d1823`
- 局部高光：电蓝 `#67e8f9`
- 局部强调：荧光黄绿 `#b7ff3c`
- 辅助能量色：暖橙 `#ff8a3d`

登录区采用浅色反差：

- 卡片背景：暖白 `#f6f2eb`
- 表单底色：半透明白 / 浅灰
- 文本主色：深灰蓝 `#17212b`

设计意图：

- 左侧像“训练智能体”的能量场
- 右侧像“可信入口”和“安全控制面板”

---

## 3. 页面结构

## 3.1 整体布局

页面采用单屏双区结构：

- 左侧：品牌介绍区，占比约 `58%`
- 右侧：登录/注册区，占比约 `42%`
- 中间：一条纵向丝滑曲线作为视觉切割

在桌面端：

- 左右同时展示
- 曲线切割保持明显

在移动端：

- 改为上下堆叠
- 登录卡片置顶
- 品牌介绍简化为一组亮点和一句主宣言

## 3.2 左侧首页内容

左侧不是“营销大字报”，而是对 FitMind 项目背景的产品化表达。

需要包含：

1. 品牌标识
   `FitMind`

2. 核心主标题
   例如：
   `把训练、状态、饮食，交给一个真正理解你的智能助手。`

3. 副标题
   强调：
   - 对话式记录
   - 健身计划与实际训练对照
   - 身体状态与饮食联动
   - 持续记忆和复盘能力

4. 功能亮点
   建议用 3 张信息卡表达：
   - `训练计划智能拆解`
   - `训练结果自动落库`
   - `状态 / 饮食 / 恢复一体记录`

5. 底部产品气质语句
   例如：
   `从今天的卧推，到长期的恢复趋势，FitMind 都会记住。`

## 3.3 右侧登录区

右侧是明亮、干净、可信的浅色区，用来承接用户操作。

需要包含两种模式：

- `登录`
- `注册`

### 登录模式

字段：

- `邮箱或用户名`
- `密码`

按钮：

- `立即登录`

辅助文案：

- 可切换到注册

### 注册模式

字段：

- `邮箱`
- `用户名`
- `密码`

按钮：

- `创建账号`

辅助文案：

- 可切换到登录

## 4. 交互动效

## 4.1 动效原则

动效要“丝滑”和“高级”，不是跳动和炫技。

要求：

- 页面加载时左侧内容分层渐入
- 曲线切割区域有缓慢流动感
- 登录卡片有微弱浮起感
- 按钮有顺滑的 hover 扩散和位移反馈
- 登录 / 注册切换要有柔和滑动和透明度过渡

## 4.2 重点动效

### 页面首屏进入

- 背景光晕先出现
- 左侧主标题延迟上浮
- 功能卡片错峰进入
- 右侧表单卡片稍晚出现

### 中轴曲线

- 使用渐变、模糊和不规则圆角做出“液态切割”
- 可以叠加一层透明高光，制造能量流线效果

### 按钮

按钮 hover 效果建议：

- 背景渐变平滑移动
- 轻微上浮
- 阴影增强
- 箭头或高光轻微滑动

---

## 5. 信息架构与文案方向

### 5.1 首页主文案

建议方向：

- 主标题偏强叙事
- 副标题偏产品能力
- 卡片偏结构化价值表达

推荐语气：

- 冷静
- 专业
- 克制
- 高级

避免：

- 过度鸡血
- 廉价健身房广告感
- 互联网模板化文案

### 5.2 登录区文案

登录区文案应该更短、更可信。

建议：

- 标题：`欢迎回来` / `创建你的 FitMind`
- 描述：`连接你的训练、恢复与饮食记录`

---

## 6. 组件清单

本页首版需要这些组件：

1. `BrandMark`
   展示 FitMind 品牌名和状态标签

2. `HeroCopy`
   首页主标题和副标题

3. `FeatureCards`
   三张功能亮点卡片

4. `CurveDivider`
   中间曲线切割层

5. `AuthPanel`
   登录 / 注册双态容器

6. `SegmentTabs`
   登录与注册切换

7. `AnimatedButton`
   高级感丝滑按钮

---

## 7. 前端实现建议

技术栈：

- React
- Vite
- Tailwind CSS

实现方式建议：

- 单页完成首页与登录区联动
- 使用 React state 管理 `login/register` 切换
- 使用 Tailwind + 少量自定义 CSS 完成复杂渐变与曲线
- 不引入重型动画库，首版以 CSS 和 Tailwind 动效为主

---

## 8. 结论

FitMind 首版首页和登录页需要传达的不是“有一个表单”，而是：

- 这是一个具备记忆与理解能力的健身智能体
- 它能把你的训练、状态和饮食连接成连续的数据旅程
- 它既有未来感，也有可信赖的产品秩序

因此首版页面采用：

`左深右浅 + 曲线切割 + 中文高质感文案 + 丝滑按钮动效 + 登录注册双态`

这份方案将作为接下来前端编码实现的直接依据。
